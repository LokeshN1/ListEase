# ListEase

ListEase is a full-stack web application for creating, managing, and sharing lists. It features user authentication, list management, and a modern responsive UI.

## Features

- User registration and authentication
- Create, edit, and delete lists
- Share lists with unique IDs
- Responsive frontend built with React and Tailwind CSS
- Secure backend with Node.js, Express, and MongoDB

## Project Structure

```
backend/    # Node.js/Express API server
frontend/   # React client application
```

## Getting Started

### Backend

1. Install dependencies:
    ```sh
    cd backend
    npm install
    ```
2. Create a `.env` file (see `.env.example` if available).
3. Start the server:
    ```sh
    npm start
    ```

### Frontend

1. Install dependencies:
    ```sh
    cd frontend
    npm install
    ```
2. Start the React app:
    ```sh
    npm start
    ```
